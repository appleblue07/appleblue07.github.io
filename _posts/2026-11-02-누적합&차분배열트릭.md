# 누적합
<br>
배열의 구간합을 O(1)의 시간에 구할 수 있는 기법입니다.<br>
그냥 배열을 입력받을 때 마다 누적합 배열의 이 전꺼에 더해서 입력해두면 구간합을 O(1)의 구할 수 있습니다<br>
<br><br>
아래틑 코드 탬플릿입니다

``` cpp

long long sum[SIZE] = {0}; //인덱스 조심하세요
int a[SIZE] = { ... };

for(int i = 1 ; i < SIZE ; i++){

    sum[i] = sum[i-1] + a[i-1];
}

//구간 l, r의 합

result = sum[l] - sum[r];

```

# 차분배열 트릭
<br>
차분배열을 이용하여 배열의 구간에 상수를 O(1)에 더할 수 있는 기법입니다.<br><br>

여기서 차분 배열은 원래 배열에서 이전 값을 뺸 것으로 차분배열을 누적합 하면 원래 배열이 나오도록 하는 배열입니다. <br>

차분 배열은 원래 배열의 누적합은 원래 배열이여서 구간 l, r에 상수를 더하려면 차분배열에 l 번째에 상수를 더하고 r에서 뺴면 그 구간에 상수가 더해집니다
<br><br>

아래는 탭플릿입니다.

``` cpp

long long a[SIZE]; //인덱스 조심하세요
long long d[SIZE];

d[0] = a[0];

for(int i = 1 ; i < SIZE ; i++){
    d[i] = a[i] - a[i-1];
}

//구간 l, r 에 상수 k 더하기
d[l] += k;
d[r] -= k;

```
