<br>
<br>

- 기능적 완전 <br>
모든 부울 함수가 이 연산자들을 사용하여 표현할 수 있으므로, 집합 {*, +, -}는 기능적 환전하다고 함<br>
ex) (*, ')는 기능적 완전<br>
ex) (+, ')는 기능적 완전<br>
ex) (*, +)는 기능적 완전하지 않음<br>
<br>
NAND 연산자 | 는 <br>
x|y = (xy)'<br>
로 정의되고 '기능적 완전함'<br>
<br>
NOR 연산자 nor(아래화살표모양) 는 <br>
x nor y = (x+y)'<br>
로 정의되고 '기능적 완전함'<br>

### problem
-----
Find the sum-of-products expansions of these Boolean functions.(useBoolean Identities)<br>
a) 𝐹(𝑥,𝑦,𝑧)=𝑥+𝑦+𝑧<br>
b) 𝐹(𝑥,𝑦,𝑧)=(𝑥+𝑧)𝑦<br>
<br>

<br>
solution : <br>
a) x+y+z // 복습 필요
x(yz + (yz)') + y(xz + (xz)') + z(xy + (xy)')<br>
xyz + x(y'+z') + y(x' + z') + z (x' + y')
<br><br>
b) x1y + z1y<br>
x(z+z')y + z(x+x')y<br>
ans : xyz + xyz' + x'yz<br>
<br>

----------

Express each of these Boolean functions using the operators ⋅and −.<br>
a) 𝑥+𝑦+𝑧<br>
b) 𝑥+𝑦'(𝑥'+𝑧)<br>
<br>


<br>

solution : <br>
a) (x'y'z')'  //(풀이에서는 두개 씩 드로르간)<br>
b) x + y'x' + y'z<br>
(x(x'y')'(y'z)')'
<br>

----------

<br><br>

Show that(useBoolean Identities, from right to left)<br>

a) 𝑥=𝑥↓𝑥<br>
b) 𝑥𝑦=(𝑥↓𝑥)↓(𝑦↓𝑦)<br>


<br>
solution : <br>
a) x' = (x + x)'<br>
x' = x'
<br>
b) xy = ((x')+(y'))' //위 식 참고 
xy = xy // 드모르간
