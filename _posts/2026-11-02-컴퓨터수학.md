### problem
-----
Find the sum-of-products expansions of these Boolean functions.(useBoolean Identities)<br>
a) 𝐹(𝑥,𝑦,𝑧)=𝑥+𝑦+𝑧<br>
b) 𝐹(𝑥,𝑦,𝑧)=(𝑥+𝑧)𝑦<br>
<br>

<br>
solution : <br>
a) x+y+z // 복습 필요
x(yz + (yz)') + y(xz + (xz)') + z(xy + (xy)')<br>
xyz + x(y'+z') + y(x' + z') + z (x' + y')
<br><br>
b) x1y + z1y<br>
x(z+z')y + z(x+x')y<br>
ans : xyz + xyz' + x'yz<br>
<br>

----------

b) 𝑥+𝑦'(𝑥'+𝑧)<br>
<br>


<br>
