# dfs와 bfs에 대해

알고리즘 배우다 보면 그냥 무조건 알게 되죠.<br> 
dfs는 deepth first search 깊이 우선 탐색 <br>
bfs는 breadth first serch 너비 우선 탐색 <br>
입니다

<br><br>
아래는 bfs코드 탬플릿입니다.


``` cpp
void bfs(){
    queue<int> q; //큐를 스택으로 바꾸면 dfs가 됩니다.

    q.push(start);

    int t;
    while(!q.empty()){
        t = q.front();
        q.pop()
        
        if(visited[t]) continue; // 찾아본곳 또 보지 않기
        for(auto u : v[t]){
            q.push(u)
        }
    }

}

// bfs, dfs는 용도에 따라 구조가 꽤 많이 바뀝니다.
// 기본 구조만 외우고 이해하면 좋을거 같습니다.
```

## 작동방식
코드의 작동 방식을 간단히 설명하면
우선 큐에 시작점을 놓습니다.<br>
그 다음 큐에서 하나를 꺼내고 그걸 제거합니다.<br>
그 다음 그 점에서 갈 수 있는 점들을 검사하면서 큐에 넣습니다.<br>
이 과정을 반복하면 모든 점을 검사할 수 있습니다.<br>
여기서 큐를 쓰는 이유는 큐는 먼저 들어온게 나중에 나오기 때문에 먼저 들어온 깊이가 낮은 노드가 먼저 검사되기 때문입니다. <br>
이와 마찬가지로 스택은 나중에 들어온 깊이가 높은 노드부터 검사하기 떄문에 깊이 우선 탐색이 됩니다. <br><br>
