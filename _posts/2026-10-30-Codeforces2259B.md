# 코드포스 2259B 문제에 대한 저의 풀이입니다

[Codeforces 2259B 문제원문](https://codeforces.com/problemset/problem/2259B)


제가 처음에 발상을 잘못해서 이상한 방법으로 구현하려다 시간 틀렸습니다. (크아ㅏㅏㅏㅏ악)

핵심발상은 모든 인덱스에 여러번 2를 빼고 양수로 바꾼다고 할 때 마지막에 나오는 수를 분류할 수 있다는 겁니다.

그 분류는
-홀수인 경우
홀수라면 계속 2를 뺴로 양수로 바꿀 때 1이 반복됩니다.

ex. 7 5 3 1 1 1 ...

-짝수인 경우
이 경우는 4의 배수인 경우와 2의 배수인 경우로 나누어 집니다

ex. 8 6 4 2 0 2 0 2 ....

ex. 6 4 2 0 2 0 2 0 ....



결국 수열에서 연산을 반복하다보면 위 3 그룹은 모두 같아지게 되기 때문에 3가지 케이스 수만 세면 답을 구할 수 있습니다.






<br>
<br>
<br>
아래는 정답코드입니다.

```cpp
#include <bits/stdc++.h>
using namespace std;


int main(void){
	int t;
	int n;
	scanf("%d", &t);

	for(int T = 0 ; T < t ; T++){
		scanf("%d", &n);
		int a;
		int c1 = 0, c2 = 0, c3 = 0;
		int ans = 0;	
		for(int i = 0 ; i < n ; i++){
			scanf("%d", &a);
			if(a%2) c1++;
			else if(a%4) c2++;
			else c3++;
		}

		ans = max(c1, c2);
		ans = max(ans, c3);

		printf("%d\n", ans);
	}
	
	return 0;
}

```
