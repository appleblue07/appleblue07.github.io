# Chapter 10


## 연산자 오버로딩

연산자를 오버로딩 하는 두 가지 방법 <br><br>

첫번째
```cpp
// 클래스 안에서 멤버함수로 오버로딩

class &operator+(class& ref){
    *this + ref; // ex
    return *this;
}
```

두번째
```cpp
//전역함수로 오버로딩 된 경우 (class 안에서 함수를 friend로 선언해야 사용 가능)

class& operator+(class& a, class& b){
    class obj = a+b; // ex 어떻게 더할지는 클래스에 따라 다름
    return a;
}
```

## 오버로딩 불가능한 연산자
<br>

| 연산자 종류 | 연산자 이름 |
|:--:|:--:|
|.|멤버 접근 연산자|
|.*|멤버 포인터연산자|
|::| 범위 지정 연산자 |
|?:| 조건연산자(3항 연산자) |
|typeid| RTTI 관련 연산자|
|static_cast, dynamic_cast, const_cast, reinterpret_cast| 형변환 연산자|

---------

- 멤버 함수의 형태로만 정의 가능
<br>

| 연산자 종류 | 연산자 이름 |
|:--:|:--:|
|=|대입연산자|
|()|함수 호출 연산자|
|[]|배열 접근 인덱스 연산자|
|->|멤버 접근을 위한 포인터 연산자|

 std 네임 스페이스에 정의 되고 <br>
cin, cout, endl 등의 객체가 정의되는 클래스(?)이다 <br>
