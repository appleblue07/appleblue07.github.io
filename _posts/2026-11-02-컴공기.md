### 시간복잡도
<br>

- 코드가 복잡하다는 뜻이 아니다<br>
<br>

### 빅오 표기
O() 안에 n으로 된 식으로 시간복잡도를 표현
<br>
<br>
<br>

- 예시
<br>
O(1) : 상수 시간<br>
O(n) :  선형 시간<br>
O(n^2) : 제곱 시간<br>
<br>
(^^)7
<br>
<br>

#### O(1), 상수 시간 <br>
n에 값에 상관 없이 연산횟수는 상수<br><br>

#### O(n), 선형 시간 <br>
n에 값에 따라 연산 횟수가 선형적으로 늘어남, n개의 입력크기는 (대략) n개의 연산<br><br>

#### O(n^2), 제곱 시간 <br>
n에 값에 따라 연산횟수가 제곱으로 늘어남.<br>
n이 두배가 되면 연산횟수는 4배가 된다.
<br><br>

### 빅오 O() 표기법은 간단하게 표현한다

n과 연산횟수가 30, 2n, n^2 + n 이라도 O(1), O(n), O(n^2)으로 표기한다.

- 하지만 n이 작은 부분에서는 저 버리는 부분이 중요할 수 있다.

## 11주차 1차시
<br><br>

### 오늘의 질문
- 100만 개 중에서 찾는 데 최악 몇 번이면 되는가?
<br>
<br>
<br>


### 용어 정리
- 탐색 : 데이터 중에서 원하는 것을 찾는 것 <br>
- 선형 탐색 : 처음부터 끝까지 하나씩 차례로 보면서 찾는 방법 (O(n))<br>
- 정렬된 상태 (sorted) : 규칙적인 순서대로 줄 서있는 상태<br>
- 이진 탐색 : "정렬된 상태"의 목록에서 가운데를 보고, 작으면 앞쪽 절반만, 크면 뒤쪽 절반만 남기는 일을 되풀이 한다.<br>

### 이진 탐색의 규칙

1. 가운데 값을 본다.
2. 찾는 값이 본 값보다 작으면 앞쪽 절반만, 크면 뒤쪽 절반만 본다.
3. 찾거나 남은 게 없을 떄 까지 되풀이 한다.


### 코드

``` python

# i want cpp

def binary_search(sorted_list, x):
    l = 0
    r = len(sorted_list) - 1
    while(l <= r):
        m = (l+r)//2
        if(sorted_list[m] == x) return m
        else if sorted_list[m] < x : l = m+1
        else r = m -1
    return -1

```

---------

반복문이 있지만 이 반복문은 n번 돌지 않는다<br>
한 번 돌 때 마다 남은 구간이 절반으로 줄어든다 <br>

### 로그 시간 O(logn)
logn : n을 반으로 몇번 나누어야 1이 되는가<br>

### 네 문제

1. 정렬된 100만개 - 최악 몇번 <br>
: 20번쯤
2. 1만 -> 100만(백 배) - 이진은 몇번 늘까<br>
3. 이진탐색을 쓰려면 목록이 어떤 상태?
4. 정렬된 연결리스트도 20번에 될까?

### 이진탐색의 두가지 조건
<br>

- 정렬되어 있어야 함
- 가운데 칸을 계산 한번으로 꺼낼 수 있어야 한다.(배열)

### 오늘의 세 문장

1. 선형 탐색은 O(n)
2. 이진 탐색은 O(logn)
3. 공짜가 아니다 (정렬, 보는데 O(1))
