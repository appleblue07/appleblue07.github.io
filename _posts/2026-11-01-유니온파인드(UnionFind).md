# 유니온 파인드 (Union find) 알고리즘 기본 템블릿입니다

```cpp

vector<int> parent(n); // 대표자를 저장해두는 배열

void init(int n) {
    for(int i = 1; i <= n; i++)
        parent[i] = i; // 처음에 대표자는 모두 자기자신임
}

int find(int x) {   
    //"대표자"를 찾는 함수
    if(parent[x] == x) return x;    //대표자가 자기 자신인 경우
    return parent[x] = find(parent[x]); //대표자가 자신이 아닌 경우 대표자를 따라감
}

void unite(int x, int y) {
    // 합치는 함수
    a = find(x);
    b = find(y);

    if(a != b)  //같은 그룹이 아니라면 합치기
        parent[b] = a;
}


```

## 유니온 파인드란?
그래프에서 점들을 같은 그룹으로 합져 문제를 해결하는 ps 개념입니다.<br>
예를 들어 점이 {1, 2, 3, 4, 5} 이 있을 떄 {1, 2, 3}, {4, 5}가 연결되어 있다고 가정해 봅시다(예시를 위해 바로 말했지만 저게 어떻게 저렇게 연결되어 있는지 모른다 가정합시다). 그리고 어떤 점들이 연결되어 있는지를 안다고 할 떄 서로 연결되지 않아 갈 수 없는 점들을 어떻게 알 수 있을까요? 이 때 쓰는게 유니온 파인드입니다. 여기서 노드를 따라가면서 서로 연결되어 있는 걸 합치고 연결되어 있지 않는 것끼리 나누어 그룹화 할 수 있습니다.

## 작동방식

기본구조에서 중요한건 parent 배열과 find(), unite() 함수입니다.
parent 는 흔히 부모(저는 "대표자"라 하겠습니다)를 가리키는 역할을 합니다. parent 의 값이 같으면 같은 집합, 연결되어있는 노드라는 뜻입니다.<br>
find() 함수는 대표자를 찾는 함수입니다. 함수 구조를 보면 이해할 수 있드시
parent[x] == x 라는 것을 자기 자신이 대표자로 이 노드가 대표 노드 입니다. 그 전에 중요한건 parent[x] = find(parent[x]) 코드 입니다 찾으려는 x가 대표자가 아닐 때 parent[x] 는 x가 아닌 대표자의 값을 저장합니다. 그리고 그 값은 다시 parent[x]의 대표자 값으로 find(parent[x])를 저장합니다 그럼 재귀가 돌아가면서 대표자를 찾을 수 있게 됩니다.<br>
find() 함수를 먼저 해서 조금 꼬이긴 했지만 unite()함수는 그 대표자가 다른 노드를 잇는 함수, 즉 합치는 함수입니다.<br>
a = find(x); b = find(y); 에서 a, b는 x, y 각각의 대표자를 저장합니다 하지만 대표자가 다르다면 parent[b] = a; 를 통해 합칩니다. <br>
조금만 더 생각해보면 parent[b] 는 b의 대표자인데 b의 대표자를 a로 지정한 다는 것을 이전에 b를 대표자로 삼던 원소들이 a를 대표자로 삼는 것으로 a, b가 같은 대표자를 가르키게 되어 유니온 파인드 기법이 성공하게 됩니다.
