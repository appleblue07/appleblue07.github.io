# 코드포스 2259D 문제에 대한 저의 풀이입니다

[Codeforces 2259D 문제원문](https://codeforces.com/problemset/problem/2259/D) 
<br>


솔직히 이 문제는 제 힘으로 풀지 못했습니다.
풀이를 찾아보니 0이 나오는 개수로 케이스를 나눌 수 있더라고요. ~~이걸 어떻게 발상하지~~

<br><br>
MEX 함수는 multiset에서 존재하지 않는 제일 작은 음수가 아닌 정수로 정의됩니다.

이거 하나만으로 케이스를 3가지로 나눌 수 있습니다.<br>

문제 조건  MEX(A) + MEX(B) + MEX(C) >= 2 * max(MEX(A), MEX(B), MEX(C)), 

주어진 집합에서

### 0이 없는 경우
어떤 경우에서도 모든 세 집합의 MEX 값은 0, <br>
0 + 0 + 0 >= 2 * 0 이므로 조건 만족

### 0이 하나인 경우
두 개의 집합에서 MEX 값이 0이 될 수 밖에 없고 하나의 집합에서 MEX 값이 0이상이 되므로 그 값이 세 집합에서 제일 크므로<br>

0 + 0 + x >= 2 * x <br>
x >= 2*x <br>

정수 집합에서 만족시키는 수가 존재하지 않으므로 no 출력

### 0 이 두개 이상인 경우

0이 두개 이상이라면,<br>
하나의 집합에 0을 제외한 수를 넣고<br> 
다른 두 집합에 0을 넣을 때 <br>

그 하나의 집합의 MEX 값은 0이 되고<br>
다른 두 집합의 MEX 값을 a, b (a != 0 && b != 0) 라 할 수 있다<br>

이 때 조건을 보면, <br>
0 + a + b >= 2 * max(a, b, 0)<br>
a + b >= 2*a 또는 a + b >= 2*b <br>
a >= b 또는 b <= a 임을 알 수 있다<br>

위 조건은 a, b 가 무슨 값인지에 상관 없이 성립한다.


## 정리

따라서 0의 개수가 하나인 경우에는 no를 출력하고 그 외에 경우는 하나의 집합에 MEX 값이 0이 되도록 배분하고 나머지 집합의 MEX 값이 0이 되지 않게 배분하면 풀리는 문제이다.




<br><br><br><br><br><br>
아래는 정답코드이다.

```cpp

#include <bits/stdc++.h>
using namespace std;



int main(void){
	int T, n;
	scanf("%d", &T);
	for(int t = 0 ; t < T ; t++){
		scanf("%d", &n);
		int a[n];
		map<int, int> cnt;
		
		for(int i = 0 ; i < n ; i++){
			scanf("%d", a+i);
			cnt[a[i]]++; //실제로는 0의 개수만 필요하므로 필요하지 않다. (다른 방식 생각하다가 실패했다.)
		}
		
		if(cnt[0] == 1){
			printf("NO\n");
			continue;
		}
		
		printf("YES\n");
		bool v = true;
		for(int i = 0 ; i < n ; i++){
			if(a[i] == 0){
				if(v) printf("A");
				else printf("B");
				v = false;
			}
			else printf("C");
		}
		printf("\n");
	}
	
	return 0;
}
```
