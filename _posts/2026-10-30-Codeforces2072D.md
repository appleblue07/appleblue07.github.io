# 코드포스 2072D 문제에 대한 저의 풀이입니다

[Codeforces 2072D 문제원문](https://codeforces.com/problemset/problem/2072/D)


이 문제도 혼자 못 풀었습니다
아직은 D 번 풀기도 벅차네요

그래도 써두면 나중에 다시 생각해보지 않을까요?
<br>

### 정리

배열의 특정 원소를 구간 뒤로 이동시키는 연산에서, 전체 역전쌍을 재계산하지 않고 이동 원소와 구간 내 원소들의 대소 관계를 비교하여 역전쌍의 변화량을 누적한다. 모든 시작점에 대해 변화량의 최댓값을 찾는다.
<br><br>
-위 설명은 gpt의 요약입니다. 나중에 제가 다시 풀게되면 설명을 추가하겠습니다.

아래는 정답코드입니다.

```cpp
#include <bits/stdc++.h>
using namespace std;


void func(){
        int n;
        scanf("%d", &n);
        vector<int> a(n+1);
        for(int i = 0 ; i < n ; i++) scanf("%d", &a[i]);
        int s = 0, e = 0, ans = 0, t;

        for(int i = 0; i < n ; i++){
                t = 0;

                for(int j = i+1 ; j < n ; j++){
                        if(a[i] < a[j]) t--;
                        if(a[i] > a[j]) t++;

                        if(ans < t){
                                ans = t;
                                s = i;
                                e = j;
                        }
                }
        }

        printf("%d %d\n", s+1, e+1);
        return;
}


int main(void){
        int t;
        scanf("%d", &t);
        for(int T = 0 ; T < t ; T++) func();

        return 0;
}

```
